# Data

This folder contains the dataset used for contextual emotion recognition.

Due to size or privacy considerations, the full dataset may not be included in this repository. A sample dataset can be provided for demonstration and reproducibility.

Expected columns include:

- dialogue_id
- turn_number
- speaker_id
- text_content
- speech_mfcc_mean
- speech_mfcc_std
- video_keypoint_x
- video_keypoint_y
- speaker_openness
- speaker_conscientiousness
- speaker_agreeableness
- speaker_neuroticism
- domain_rule_applicable
- emotion_label
- emotion_intensity
- dataset_source
